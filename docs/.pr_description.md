# Pull Request: Add MinerVsEverything static site (docs/)

This PR adds a responsive GitHub Pages-ready static site for the MinerVsEverything channel under the docs/ directory.

Highlights
- Interactive probability demos: UUID collision, identical deck shuffles, random Lorem Ipsum typing.
- Configurable miner/network assumptions for probability comparisons.
- Satirical visitor estimate displayed as a random "probably" number (replaceable with a real global counter later).
- Color scheme and visuals styled to match the provided channel DP and banner.

Files added
- docs/index.html
- docs/styles.css
- docs/script.js
- docs/README.md
- docs/assets/* (placeholders)

Deployment
After merge, enable GitHub Pages in repository Settings with Source set to branch: default and folder: /docs
