How comparison works

We compute an event probability P_event and compare it to a miner's per-block chance: P_miner = miner_hash_rate / (network_hash_rate_in_Hps). For network hash rate we use the "EH/s" value you provided (1 EH/s = 10^18 hashes/sec) and assume a block occurs every 600 seconds (Bitcoin-like).

All computations are approximate and intended for satirical/educational demonstration.
